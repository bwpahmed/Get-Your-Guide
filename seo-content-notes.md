# SEO Content Hub

This branch adds original, editable content for:

- Homepage cruise and tour guidance
- Dubai dhow cruise guide
- Dubai Canal cruise guide
- Dubai Marina cruise guide
- Dubai Creek cruise guide
- Dubai New Year cruise guide and policies

All guide headings, paragraphs, list items, visibility and ordering are editable from `/admin` using the **SEO Pages** control. The public visual system remains unchanged.

The New Year page intentionally avoids publishing invented prices, vessel names, guaranteed fireworks views or cancellation terms. Those details must be added only after the operator confirms them.
